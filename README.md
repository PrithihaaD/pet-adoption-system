🐾 Pet Adoption & Veterinary Care System

A full-stack web application developed using PHP, MySQL, HTML, CSS, and XAMPP.
This system helps users adopt pets, book veterinary appointments, and enables staff and veterinarians to manage operations efficiently.

---

🚀 Features

- User Registration and Login
- Pet Adoption Requests
- Appointment Booking with Veterinarians
- Vet Schedule Management
- Treatment and Medication Records
- Staff Management System
- Role-based Access (User / Staff / Vet)
- Simple and User-Friendly Interface

---

🛠️ Technologies Used

- Frontend: HTML, CSS
- Backend: PHP
- Database: MySQL
- Server: XAMPP

---

📂 Modules

👤 Adopter Module

- Register & Login
- View Available Pets
- Send Adoption Requests
- Book Vet Appointments
- View Treatments & Medications

---

🧑‍💼 Staff Module

- Manage Adoption Requests
- Add / Manage Pets
- View Vet Availability
- Manage Appointments

---

👨‍⚕️ Veterinarian Module

- Add & Manage Schedule
- View Approved Appointments
- Add Treatment Details
- Add Medication (Dosage & Duration)

---

🔄 Workflow

1. User registers and logs in
2. User sends adoption request or books appointment
3. Staff manages requests
4. Veterinarian sets availability
5. Veterinarian provides treatment & medication
6. User views treatment history

⚙️ How to Run the Project

1. Install XAMPP
2. Start Apache and MySQL
3. Copy the project folder into:
   C:\xampp\htdocs\
4. Open phpMyAdmin
5. Import the database file (".sql")
6. Open browser and run:
   http://localhost/pet_adoption/
